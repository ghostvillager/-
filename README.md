# 複数デバイス同時再生 (SimpleMultiAudio)

Windowsでシステム音声を複数の再生デバイスに同時出力する、超シンプルなツールです。

## 特徴
- 日本語UI
- 出力デバイスを複数選択するだけ
- 常にシステム音声（ループバック）固定
- 起動時に自動でトレイに収納
- 選択したデバイスを記憶し、次回起動時に自動開始
- 二重起動防止
- 余計な機能なし

## 必要なもの
- Windows 10 / 11
- .NET 8 Desktop Runtime（持っていない場合は自動で促されます）

## ビルド方法
1. Visual Studio 2022 で `SimpleMultiAudio.csproj` を開く
2. またはコマンドラインで：
   ```
   dotnet build -c Release
   ```
3. 生成された `bin\Release\net8.0-windows\SimpleMultiAudio.exe` を実行

## 使い方
1. 初回起動時にデバイス一覧が表示されます
2. 使いたいデバイスにチェックを入れる
3. 「開始」を押す
4. 自動でトレイに隠れます
5. 次回からは起動するだけで自動開始されます

トレイアイコンを左クリックで設定ウィンドウを開きます。
右クリックメニューから「再起動」「終了」ができます。
二重起動は防止され、2回目以降の起動は既存のウィンドウを前面に出します。

## 起動時自動開始
`Win + R` → `shell:startup` にショートカットを置いてください。
